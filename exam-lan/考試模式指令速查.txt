====================================================================
 區域網路上機考試  指令速查
====================================================================
OJ 網址：http://192.168.50.163/
所有指令都在 PowerShell 執行。

注意：.env 的 DJANGO_ALLOWED_HOSTS 最後面要有 192.168.50.163
      (只追加，原有的不要刪)，否則網頁會出現 400 Bad Request。


[0] 下載 letsoj
    git clone https://github.com/dr-chenglung/letsoj.git
    cd letsoj
    


[1] 解壓 nginx 到 C 槽根目錄
    到 https://nginx.org/en/download.html 下載 Stable version 的 zip，
    解壓後資料夾改名為 C:\nginx
    (C:\nginx 底下要直接看到 nginx.exe、conf、logs、temp)


[2] 用我們的 conf 檔取代 nginx 的設定檔
   letsoj\exam-lan\windows-nginx\conf\nginx.conf 複製到 C:\nginx\conf\nginx.conf

    檢查 (看到 syntax is ok 就對了)：
        cd C:\nginx
        .\nginx.exe -t


[3] 啟動 / 停止 nginx (都要先 cd C:\nginx)
    啟動：
        cd C:\nginx
        start nginx
    第一次啟動會跳出 Windows 防火牆視窗，不要改勾選，直接按「允許」；要保險就兩個都勾。
    (視窗預設會勾好網卡目前的類型，考場常是「公用網路」；改成只勾私人網路，學生會連不進來)

    學生連不進來時，檢查網卡類型與 nginx 防火牆規則 (規則的 Profile 要包含網卡的類型)：
        Get-NetConnectionProfile
        Get-NetFirewallRule -DisplayName "*nginx*" | Format-Table DisplayName,Action,Profile,Enabled
    補救 (系統管理員 PowerShell)，讓 nginx 在所有網路類型都放行：
        Get-NetFirewallRule -DisplayName "*nginx*" | Set-NetFirewallRule -Action Allow -Profile Any

    停止：
        cd C:\nginx
        .\nginx.exe -s quit
    停不掉時強制結束：
        taskkill /F /IM nginx.exe


[4] 啟動 OJ 的 Docker Compose (考試模式)
    cd letsoj
    
    docker compose -f docker-compose.yaml -f docker-compose.exam.yaml up -d

    啟動後開瀏覽器進入：
        http://192.168.50.163/


[5] 匯入資料庫 dump 檔
    把 dump 檔放到 letsoj\oj-postgres-dump-backup\pg_backup_00.dump
    (檔名不同就改 restore-postgres.ps1 裡的 $dumpFileName)

    cd letsoj\oj-db-dump-on-windows
    .\restore-postgres.ps1

    匯入完成後重新進入 http://192.168.50.163/ ，就能看到網頁正常運作。


[6] 考試結束：回到一般模式
    先關 Windows 本機 nginx (它占著 port 80，不先關容器會搶不到 80)：
        cd C:\nginx
        .\nginx.exe -s quit

    再以一般模式重啟容器 (不用先刪容器，Compose 會自動重建 oj-nginx)：
        cd letsoj
        docker compose up -d

    確認 (看到 80/tcp -> 0.0.0.0:80 就對了)：
        docker port oj-nginx
    若還是 127.0.0.1:8080，強制重建：
        docker compose up -d --force-recreate oj-nginx

    注意：千萬不要用 docker compose down -v，-v 會刪掉 volume，資料庫會被清空。
