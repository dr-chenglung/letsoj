上機考試管理(Exam Management)

📋 區域網路上機考試操作指南(點開查看完整設定與步驟)
一、各項管制的差別
管制擋什麼衝突時誰勝出何時檢查
只允許以下IP登入 教室外的電腦登入 — 登入時
只允許考生有一個登入(單一登入) 同一帳號同時在兩處使用 後登入者勝，先登入者被踢掉(作弊者進得去，只能事後從「多次登入」發現) 登入時
考試模式：IP 綁定 在別台電腦用別人的帳號；同一台電腦登入兩個帳號(換瀏覽器、無痕視窗) 先綁定者勝，後來的直接被拒絕(作弊者進不去) 登入時

登入時的檢查順序：帳號密碼 → IP 白名單 → 考試 IP 綁定 → 登入 → 單一登入。管理者帳號不受這些管制。

二、第一次準備(只需做一次，詳見專案的 exam-lan/README.md)
  1. 在伺服器(Windows)安裝 nginx for Windows，並放入 exam-lan/windows-nginx/conf/nginx.conf。 原因：Windows 的 Docker Desktop 看不到學生電腦的真實IP，要靠 Windows 本機 nginx 轉交真實IP。
  2. 伺服器設定固定IP(例如 192.168.0.10)，並把這個IP追加到 .env 的 DJANGO_ALLOWED_HOSTS(原有項目不要刪)。
  3. 關閉教室 Router 的 Wi-Fi，避免學生手機連進考試網段。
三、開考前步驟(每次考試)
  1. 以考試模式啟動：docker compose -f docker-compose.yaml -f docker-compose.exam.yaml up -d，再啟動 Windows 本機 nginx(cd C:\nginx、start nginx)。
  2. 用一台教室電腦登入管理者帳號、開啟本頁，確認下方「伺服器看到你目前的IP」顯示 192.168.0.x。 若出現紅字警告，代表網路設定沒做好，不可打開 IP 綁定(會擋住所有考生)。
  3. 按「清除所有綁定與被拒紀錄」，清掉上一次考試的資料(會同時登出所有考生)。
  4. 打開「考試模式：IP 綁定」開關。打開時會自動登出所有考生，考生要重新登入，重新登入的那台電腦就會被綁定。
  5. (建議)打開「只允許以下IP登入」，填入 192.168.0.0/24，多一層保險。
  6. (可選)「只允許考生有一個登入」可開可不開；IP 綁定已涵蓋它的防護，開著可多一份紀錄。
  7. (建議)在頁面最下方「其他系統設定」打開「禁止使用者變更密碼」，並確認「禁止新使用者註冊」已開啟。
  8. 請學生在自己的座位電腦登入 OJ。
四、考試中
  • 學生要換電腦(電腦故障、當機)：在「考試IP綁定名單」找到他按「解除」(會同時登出他)，再請他到新電腦登入。
  • 學生反映「此帳號已綁定在另一台電腦」或「這台電腦已經登入過其他帳號」：查看「被拒紀錄」，確認是換電腦還是代考。
  • 考試中請勿切換 IP 綁定開關：關閉期間任何人都能在任何電腦登入任何帳號；再打開時會登出全班。
  • 瀏覽器當掉重開：學生在同一台電腦重新登入即可，不需要老師處理。
五、考試結束
  1. 關閉「考試模式：IP 綁定」開關，並視需要關閉「只允許以下IP登入」。綁定資料留著無妨，下次開考前再清除。
  2. 關閉 Windows 本機 nginx：cd C:\nginx、.\nginx.exe -s quit。
  3. 以一般模式重啟容器：docker compose -f docker-compose.yaml up -d(必須先關 Windows nginx，容器才拿得回 80 port)。
六、常見情境(開啟 IP 綁定時)
情境結果
學生 A 在自己的電腦考完、登出後，想在同一台電腦登入缺考同學的帳號替他作答 被拒絕。這台電腦的IP已綁定 A，不能再綁定其他帳號。
學生 A 想在自己的電腦登入已經在別台電腦考試的同學的帳號 被拒絕。該同學的帳號已綁定在他自己的電腦，而且 A 的電腦也已綁定 A。
學生 A 在自己的電腦換瀏覽器或開無痕視窗，登入別人的帳號 被拒絕。同一台電腦不論用哪個瀏覽器，IP 都相同。
校外或教室外的人拿到 A 的密碼想登入 連不到伺服器(教室網路已斷外網)；就算在教室內別台電腦登入也會被拒絕。
瀏覽器當掉，學生在同一台電腦重新登入 允許，不需要老師處理。
學生的電腦故障，要換到另一台電腦 被拒絕，須由老師在「考試IP綁定名單」按「解除」後，學生才能在新電腦登入。
⚠ 學生 A 走到沒有人使用的空位電腦，登入缺考同學的帳號 擋不住：空位電腦與缺考同學的帳號都還沒綁定。須靠監考與事後比對： (1) 監考時注意學生離開座位使用其他電腦； (2) 用「查詢未登入的學生」掌握缺考名單； (3) 在「考試IP綁定名單」檢查缺考名單中的帳號是否後來出現、綁定時間是否明顯晚於開考。
七、本頁其他按鈕與開關說明
按鈕／開關作用何時使用
清理Session紀錄 讓所有考生(管理者除外)目前的登入全部失效，必須重新登入。 開考前。若有開 IP 綁定，打開開關時已會自動登出考生，可不必另外按。
停止任何人登入，或只允許以下IP登入 IP 白名單：只有填入網段內的電腦能登入(用逗號分隔，例如 192.168.0.0/24)；不填任何IP則除管理者外無人能登入。 考試時建議開啟。修改IP後要把開關關掉再打開才會生效。需架好 Windows 本機 nginx 才有效。
只允許考生有一個登入 同一帳號再次登入時，前一個登入會被踢掉，並記入「有多次登入的考生」。作弊者仍進得去，只能事後發現。 可開可不開。開啟 IP 綁定後，別台電腦的登入會先被綁定擋下，不會踢掉本人。
競賽尚未結束，不顯示已經提交成功的程式碼 競賽進行中隱藏「已通過」的程式碼，帳號外流時他人也看不到已通過的答案。 考試時建議開啟。
禁止新使用者註冊 關閉註冊頁面，避免考試中有人註冊新帳號。 平常與考試時都建議開啟。
禁止使用者變更密碼 考生不能修改密碼。 考試時建議開啟，避免考生在考場改密碼後忘記。
顯示考生多次登入與被拒絕IP情況 列出「被 IP 白名單拒絕」與「單一登入被踢掉」的紀錄。 考試中或考後查看，追查可疑的登入。
清除前一次的考生被拒絕IP、多次登入、登入登出紀錄 刪除被拒絕IP、多次登入、登入登出紀錄這幾份舊紀錄。不會刪除考試IP綁定名單。 新考試開始前做一次。注意：「查詢未登入的學生」是依登入紀錄判斷，清除後要等學生重新登入才查得到。
考試模式：IP 綁定 一個帳號只能在一台電腦使用，一台電腦只能使用一個帳號。打開時會登出所有考生。 考試時開啟；考試中請勿切換。
顯示綁定名單與被拒紀錄 列出每個帳號綁定的IP與時間，以及被綁定擋下的紀錄(原因、IP、時間)。 考試中隨時查看；學生換電腦時在名單按「解除」。
清除所有綁定與被拒紀錄 刪除所有考試IP綁定與被拒紀錄，並登出所有考生。 新考試開始前做一次；考試中請勿按。
查詢未登入的學生 從下拉選單選擇班級，列出該時間點後沒有登入紀錄的學生(未填時間則為三小時內)，可當作缺考名單，同時顯示登入登出紀錄。 考試開始約半小時後，選擇當天應考的班級查詢，時間點不填即可。
